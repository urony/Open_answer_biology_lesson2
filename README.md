# כותבים הסבר תהליכי

כלי אינטרנטי בעברית (ימין לשמאל, מותאם לנייד) שמלמד תלמידים לכתוב הסבר תהליכי בביולוגיה, לפי המצגת "איך כותבים תשובה".

זרימה: תרגיל ניסיון ← לימוד ← תיקון עם משוב אוטומטי ורפלקציה ← תרגול נוסף ← דוח PDF לשליחה בוואטסאפ.

## הרצה
אתר סטטי, בלי שרת. פותחים את `index.html`, או מפעילים GitHub Pages (Settings ← Pages ← Deploy from branch ← main / root).

## הגדרות
בקובץ `config.js`: מספר הוואטסאפ של המורה (`972501234567`) ושם המורה.

## מבנה
- `content.js` שאלות, שלבי התהליך ותשובות לדוגמה
- `check.js` המשוב האוטומטי (בדיקה לפי כללים, לא AI)
- `report.js` יצירת הדוח (PDF / תמונה)
- `app.js`, `styles.css`, `index.html` הממשק
